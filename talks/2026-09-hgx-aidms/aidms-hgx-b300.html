AIDMS 的基礎設施價值

✓Ready-to-use Model Library
預載以 vLLM 運行的常用 LLM，也支援自行封裝與匯入模型；標準化 Runtime 可降低部署與環境配置差異。
✓Model Lifecycle Control
透過 Model Version Control 清楚管理使用中的模型版本，降低版本混用風險。
✓No-code Launch & API Service Delivery
透過圖形化介面啟動 LLM，並以統一的 API Endpoint 提供給 AI Applications 或 Agents 使用。
✓Project-based GPU Sharing
依 User 與 Project 管理 GPU 配置與共享，讓多個團隊共同使用 HGX B300 算力。
✓Centralized AI Operations
集中掌握模型、服務、GPU 配置與使用狀態，建立一致的營運視角。
✓Multi-node Management
從單台 HGX B300 延伸到多台伺服器，維持集中的管理與使用方式。
AIDMS 的角色，是讓 Agent 背後的模型、服務與 GPU 基礎設施維持穩定、清楚且容易管理。
